# Screenshots

Save your screenshots here with these names so the links in the main README work.
Use the app's `?pause` link before taking app screenshots so the page stops refreshing.

|---|---|

| `02-app-az-a.png` | The app page served from the first Availability Zone |
| `03-app-az-b.png` | The app page served from the second Availability Zone |
| `04-targets-healthy.png` | Target group **Targets** tab with two healthy targets in two AZs |
| `05-target-unhealthy.png` | One target **unhealthy** after you open the `/fail` demo link |
| `06-asg-activity.png` | Auto Scaling group **Activity** tab showing the terminate and the replacement launch |
| `07-alarm-email.png` | The CloudWatch alarm email (ALARM, then OK) |
| `08-stack-deleted.png` | Cleanup: the stack showing **DELETE_COMPLETE** |

Before you publish, check each screenshot for anything private: your account ID, email address, or access keys.
Crop or blur them out.
